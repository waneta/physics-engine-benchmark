# RULES

## 1. 目录规则

### 允许修改

- 待填写白名单目录

### 禁止修改

- 生成产物目录
- 秘钥和本地配置目录
- 未经批准的核心目录

## 2. 代码规则

- 命名规范
- 注释规范
- 依赖引入规范
- 重构边界

## 3. 测试规则

- 哪些改动必须补测试
- 哪些测试必须跑
- 哪些失败可阻断合并

## 4. 命令规则

### 直接允许

- 只读查询命令
- 低风险格式化和静态检查命令

### 需要人工批准

- 删除类命令
- 批量改名命令
- 发布类命令
- 修改生产配置的命令

## 5. 兼容性规则

- 公共接口兼容策略
- 数据格式兼容策略
- 版本升级策略

## 6. 回写规则

- 任务执行前后必须更新 `runtime/`
- 关键决策必须写入 `docs/DECISIONS.md`
- 稳定结论要沉淀到 `memory/repo.md`
