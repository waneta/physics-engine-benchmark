# PRD

建立可复查的机器人仿真物理引擎对比实验。task01 已建立 CPU 基线；task02 将相同的
滑块停止、方块下落和单铰链摆动接入 MuJoCo-Warp、Genesis、Isaac Sim/PhysX，保存跨引擎原始数据和曲线。

验收：三个场景、每场景两种步长、每种三次独立重复；质量和惯量等导入参数校验；
接触力与动量一致性校验；铰链独立 ODE 参考；锁定环境并保存成功与失败记录。

GPU 刚体后端包括直接 MuJoCo-Warp 与 Genesis，PhysX 使用 Isaac Sim 的 CPU TGS 路径。
用户后续已扩展范围：完成碰撞链、Panda 操作、插销、软体、控制器调参和吞吐实验。
吞吐测试独立于带诊断采样的物理测试；明确数值失败和任务失败的差别。
原文资产和完整配置尚未取得，自选参数必须标记，不声称精确复现作者数字。
正式实验定义与使用说明位于 `docs/benchmark.md` 和 `docs/multi-engine.md`。


task04 优先完成单物体滑动方块：四引擎可逐个选择有界面或无界面，保存摩擦力与轨迹
测试结果及中文汇总。下落、铰链的新增调整留待后续任务；完整扩展补跑继续暂停。


task04补充信息要求指标名称、单位与值的说明中英文并列；数字保留原始精度，
布尔值与缺失值提供双语展示，汇总可由已有实测再导出，保留历史结果与来源。

task04第4条继续立方体下落、碰撞、静置：四引擎可逐个运行有界面或无界面，
保存两步长各三重复、碰撞与回弹、自由落体参考、包含转动和地面支撑的刚体静置指标。
输出中英文名称、单位、数值和重复统计，界面逐步核对；完整扩展补跑继续暂停。
