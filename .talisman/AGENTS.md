# 项目 AGENTS 宪章

## 1. 项目目标

- 用一句话描述当前项目的核心目标。
- 明确当前阶段最重要的 1 到 3 个目标。

## 2. 单一事实源

1. `docs/` 说明为什么做、做成什么样
2. `spec/` 说明系统如何理解任务、模块、依赖
3. `runtime/` 说明当前做到哪里、卡在哪里
4. `memory/` 记录稳定结论和阶段性经验

## 3. 允许修改的目录

在这里列白名单，不要写成全仓可改。

示例：

- `src/`
- `tests/`
- `docs/`

## 4. 禁改目录和高风险路径

至少列出：

- 生成产物目录
- 密钥和配置目录
- 发布脚本
- 核心算法或兼容性敏感代码

## 5. 工作流程

1. 先读 `docs/PRD.md`、`docs/ARCH.md`、`docs/RULES.md`
2. 再读 `spec/tasks.yaml` 和 `runtime/state.yaml`
3. 只执行 `status=ready` 且输入齐全的任务
4. 执行前后更新 `runtime/`
5. 完成后回写验收结果

## 6. 命令规则

1. 默认允许只读命令
2. 写文件、构建、发布、删改类命令按 `docs/RULES.md` 执行
3. 高风险命令必须进入人工 gate

## 7. Done 定义

任务只有同时满足下面条件才算 done：

1. 代码或文档产出已完成
2. 必要测试已通过
3. `runtime/state.yaml` 已回写
4. 验收结果已写入任务记录
