# dev_docs 说明

`dev_docs` 用于存放开发者编写的开发任务技术文档。

## 目录定位

1. 面向开发者与 AI 协作的任务说明文档。
2. 记录任务背景、技术方案、执行步骤、验收口径。
3. 属于阶段性沉淀，不替代 `docs/` 的正式规范文档。

## 建议内容结构

每个任务文档建议包含：

1. 任务目标
2. 影响范围
3. 技术方案
4. 执行步骤
5. 风险与回滚点
6. 验收标准

## 命名建议

1. `task_yyyy_mm_dd_主题.md`
2. 或 `专题_主题.md`

## 与其他目录的关系

1. `docs/`：正式规范与长期稳定规则。
2. `spec/`：结构化配置与机器可读任务信息。
3. `runtime/`：执行状态与过程记录。
4. `dev_docs/`：开发者任务的技术说明与阶段性沉淀。
